Project Panopticon: Intelligent Exam Proctoring

This project builds an intelligent time-series machine learning pipeline for detecting suspicious behavior during online examinations.

Features

- Asynchronous time-series merging using Pandas
- Missing value handling with interpolation and forward filling
- Rolling-window feature engineering
- Random Forest classification
- Precision-focused decision threshold (90%)
- Precision–Recall curve evaluation

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

This project was developed as an AI/ML capstone project focused on reducing false accusations in automated exam proctoring systems.
